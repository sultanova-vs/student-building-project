Тема работы: основы GitHub
Цель: освоение базовых практических навыков работы с платформой GitHub
Перечень выполненных действий:
1) регистрация на платформе GitHub
2) создание репозитория
3) оформление файла README с описанием учебного проекта
4) создание и редактирование файла отчета
5) выполнение коммитов и ознакомление с историей изменений
Вывод: GitHub удобная платформа для хранения файлов и отслеживания изменений, а так жэе коллективной работы 
Применение в строительстве:для совместной работы над проектами, хранения кода, автоматизации процессов и поиска решений. Сервис основан на распределённой системе контроля версий Git и позволяет разработчикам делиться кодом, отслеживать изменения и управлять проектами.
